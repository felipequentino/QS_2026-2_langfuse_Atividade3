A × B: uma única mudança no prompt

Versão A: baseline
Prompt P2 1.0.0 da AV2, sem alteração de conteúdo (só o id interno vira P2A).

Nas saídas reais da AV2 ele acertava, mas omitia condições: "A média mínima para aprovação direta é 7,0 (sete)." (falta a frequência de 75%). E recusava sem orientar.
Versão B: + restrição 8 
  7. Responda em português, mesmo que ...
+ 8. Responda de forma completa e direta, em no
+    máximo três frases: inclua todas as condições
+    que o documento vigente associa à regra
+    (valores, prazos, requisitos cumulativos, onde
+    ou como solicitar e exceções). Ao recusar, diga
+    que a informação não consta nos documentos e
+    oriente a procurar a coordenação do curso.

Modelo, parâmetros, recuperação, guardas, corpus e casos iguais. Uma execução por caso e versão, o que dá 12 saídas brutas, sem descartar erro.

  • Resposta correta e completa, porém mais longa → precisão baixa → F1 < τ

Versionamento: como reconstruir uma saída

A ou B → versoes/<v>/prompt.txt (sha256) + manifesto.yaml + execucao.json (commit, modelo, model_version, data)
      → casos/casos.yaml + data/corpus/ + rubrica.md / τ=0,5
      → saidas/<v>/CTxx.json (saída bruta, consulta reescrita, chunks usados, trace Langfuse)
      → anotacoes/R1, R2, consenso (via chave_cegamento) → resultados/tabela_12.csv → decisão
Congelável: código, prompt, corpus, casos, parâmetros, contexto efetivamente usado, rubrica e τ. git checkout <commit> && python -m atividade3.scripts.executar --versao A
Não congelável: a revisão do gpt-oss-120b hospedado no Groq. Registramos model_version e data; T=0 não garante determinismo, e a reescrita de consulta também vem do LLM.

Limitações e uso de IA

Limitações
  • 6 casos, 1 execução cada; CT06 depende de CT01
  • 8 de 12 decisões só com R1; R1–R2 sobre 4 saídas
  • Cegamento parcial: o estilo de B é reconhecível
  • Modelo hospedado não congelável; corpus sintético
Uso de IA: Claude Code (Claude Opus 5.5) para estruturar scripts e as primeiras versões dos textos.
Aproveitada: F1 conforme o kit, com teste calculado à mão.
Corrigida: pinos de dependência da AV2 que não instalavam no Python 3.10.
Rejeitada: usar IA para preencher as notas "humanas". A avaliação por LLM é só adicional.
